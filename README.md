# movix-app – Movie Library App

Movix is a web application for browsing, filtering, and managing movies. Users can search, filter by genres, rate movies, and mark them as favorites.

## Features

- Browse movies
- Search movies by title
- Filter by genre
- Sort by title, year, or rating
- Add and remove favorites
- Rate movies
- Create and edit movies
- Responsive design (mobile & desktop)

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

## Getting Started

1. Clone the repository:

git clone https://github.com/tautaussn-oss/movix-app.git

2. Install dependencies:

npm install

3. Run the development server:

npm run dev

4. Open in browser:

http://localhost:3000
